USBTOGGLE DATA MODELS
=====================
All schemas, entities, interfaces and types used by usbToggle.
Rust types are serialized with serde; "wire name" is the JSON field name (camelCase).
Paths are relative to usbToggle/.

==============================================================================
1. IPC ENTITIES (back end -> window)
==============================================================================

Device  (src-tauri/src/devices.rs)  - one physical USB device
------------------------------------------------------------------------------
wire name      Rust type              notes
id             String                 Windows device instance ID; identity of the device
defaultName    String                 automatic display name
name           String                 customName if set, else defaultName
customName     Option<String>         user-chosen name (null when not set)
description    String                 Windows device description (SPDRP_DEVICEDESC)
vendor         Option<String>         company name from the VID table
vid            Option<String>         4 hex digits, upper case
pid            Option<String>         4 hex digits, upper case
category       Category               see Category below
present        bool                   connected now
enabled        bool                   not disabled in Windows
problem        u32                    problem code for connected devices; 0 = OK; 22 = disabled
isHub          bool                   USB hub
hubId          Option<String>         instance ID of the external parent hub
hubName        Option<String>         display name of that hub
port           Option<u32>            port number on the parent hub (from Port_#NNNN)
builtIn        bool                   part of the PC (machine container / not removable)
panel          Option<&'static str>   "front" | "back" | "left" | "right" | "top" | "bottom"
lastSeen       Option<i64>            last arrival (present) or removal (absent), Unix ms
functions      Vec<String>            readable names of functions below the device; empty for hubs
pinned         bool                   pinned by the user
locked         bool                   protected: cannot be turned off (can be turned on)
autoLocked     bool                   protected by the keyboard/mouse rule, not by the user
customIcon     Option<String>         icon chosen by the user ("mic", "l-guitar", ...); null = category icon
Invariants: id is unique in a list; name is never empty; hubId is never a root hub or a built-in hub;
problem is 0 when present is false; functions is empty when isHub is true.

Category  (src-tauri/src/classify.rs)  - enum, serialized lowercase
------------------------------------------------------------------------------
keyboard | mouse | input | gamepad | audio | camera | storage | phone | bluetooth | network |
printer | serial | security | hub | other
Labels (Category::label): Keyboard, Mouse, Input device, Game controller, Audio device, Camera,
Storage, Phone, Bluetooth adapter, Network adapter, Printer, Serial device, Security key, USB hub,
USB device. (The window uses its own label table, e.g. "Keyboard & mouse" for input.)

Snapshot  (src-tauri/src/lib.rs)
------------------------------------------------------------------------------
devices        Vec<Device>            sorted by name (case-insensitive), then id
busy           Vec<String>            IDs with an operation in progress, sorted
scannedAt      i64                    last scan time, Unix ms; 0 before the first scan
error          Option<String>         last scan error

AppInfo  (src-tauri/src/lib.rs)
------------------------------------------------------------------------------
version        String                 package version
elevated       bool                   process is elevated
settings       Settings               current settings
autostart      AutostartState         startup registration
configPath     String                 full path of config.json
logDir         String                 full path of the log folder
portable       bool                   portable mode
configError    Option<String>         message produced while loading config.json

ToggleResult  (src-tauri/src/lib.rs)
------------------------------------------------------------------------------
ok             bool
code           Option<&'static str>   "locked" | "accessDenied" | "notDisableable" | "missing" | "failed"
message        Option<String>         error text, or the restart notice
needsRestart   bool                   restart required, or the device did not reach the requested state
snapshot       Snapshot               list after the operation

AutostartState  (src-tauri/src/autostart.rs)
------------------------------------------------------------------------------
enabled        bool                   task or Run value exists
elevated       bool                   the scheduled task exists (elevated start)

Event payloads
------------------------------------------------------------------------------
"devices"      Snapshot
"busy"         Vec<String>            IDs in progress (unsorted)
"toast"        { kind: "error", message: string|null, code: string|null }

==============================================================================
2. PERSISTED SCHEMA: config.json
==============================================================================
Location: %APPDATA%\usbToggle\config.json (portable: <exe dir>\data\config.json)
Encoding: UTF-8 JSON, pretty-printed. Written atomically (config.json.tmp then rename).

Config  (src-tauri/src/config.rs)
------------------------------------------------------------------------------
schemaVersion  u32                         current = 3
settings       Settings
devices        BTreeMap<String, DeviceSettings>   key = upper-case instance ID

Settings
------------------------------------------------------------------------------
field             type     default    meaning
theme             String   "system"   "system" | "light" | "dark"
closeToTray       bool     true       closing the window hides it
startMinimized    bool     true       start hidden when launched with --autostart
showDisconnected  bool     false      list remembered devices that are not plugged in
showHubs          bool     false      list USB hubs
portsOnly         bool     true       hide devices built into the PC
confirmRisky      bool     true       confirm before turning off keyboards, mice, hubs, Bluetooth
hideProblems      bool     true       hide connected devices with a problem code other than 22
protectInput      bool     true       "Protect devices": keyboards, mice and keyboard+mouse are protected automatically;
                                      while on, protected devices cannot be unprotected

DeviceSettings
------------------------------------------------------------------------------
name              Option<String>   omitted when null
pinned            bool             omitted when false
locked            Option<bool>     omitted when null; true = protected by the user (an old false has no effect)
icon              Option<String>   omitted when null; icon name from ui/icons.js or "l-<lucide name>"
An entry with no name, pinned=false, no lock choice and no icon is removed.

Example:
{
  "schemaVersion": 3,
  "settings": {
    "theme": "dark",
    "closeToTray": true,
    "startMinimized": true,
    "showDisconnected": false,
    "showHubs": false,
    "portsOnly": true,
    "confirmRisky": true,
    "hideProblems": true,
    "protectInput": true
  },
  "devices": {
    "USB\\VID_046D&PID_0825\\ABC123": { "name": "Desk webcam", "pinned": true, "locked": true, "icon": "l-video" },
  }
}

Schema history and migration
------------------------------------------------------------------------------
v1  Original Tauri prototype (devices stored as an array). Does not match the current shape, so it is
    treated as damaged: backed up to config.<timestamp>.bak.json and replaced by defaults.
v2  Current shape without portsOnly; showHubs/showDisconnected defaulted to true.
v3  Adds portsOnly. Loading v1/v2 sets portsOnly=true, showHubs=false, showDisconnected=false once.
    Later added within v3: hideProblems, protectInput, devices.<id>.locked and devices.<id>.icon (missing in
    older v3 files, so they take their defaults).
>3  Not supported: defaults are used and a message is shown; the file is left as is until the next save.
Damaged JSON: copied to config.<yyyyMMdd-HHmmss>.bak.json, defaults used, message shown.

==============================================================================
4. WINDOWS DATA INTERPRETED BY THE APP
==============================================================================
Instance ID           "USB\VID_xxxx&PID_yyyy[&MI_nn]\<serial or port-based id>"
                      &MI_nn = interface of a composite device; ROOT_HUB* = root hub.
Machine container     {00000000-0000-0000-ffff-ffffffffffff}
Config flags          bit 0x1 CONFIGFLAG_DISABLED = disabled persistently
Capabilities          bit 0x4 CM_DEVCAP_REMOVABLE
Problem codes         22 = disabled; others mapped to text in ui/app.js (PROBLEMS)
_PLD buffer           byte 0 bits 0-6 = revision (0 = invalid);
                      DWORD at byte 8: bit 0 UserVisible, bits 3-5 Panel
                      (0 top, 1 bottom, 2 left, 3 right, 4 front, 5 back, 6 unknown)
Location information  "Port_#NNNN.Hub_#NNNN"

5. FRONT-END STATE (ui/app.js)
==============================================================================
state.loaded       boolean              first snapshot received
state.devices      Device[]             last snapshot list
state.byId         Map<string, Device>
state.busy         Set<string>          from the back end ("busy" event / snapshot)
state.pending      Map<string, boolean> optimistic target state while a request is running
state.scannedAt    number

state.settings     Settings             (DEFAULT_SETTINGS merged with AppInfo.settings)

Settings dialog draft (module variable "draft" in ui/app.js; null while the dialog is closed)
draft.settings     Settings            working copy; applied only by Save
draft.autostart    boolean             wanted "Start with Windows" state; applied only by Save
Dirty = any draft.settings field differs from state.settings, or draft.autostart differs from
state.info.autostart.enabled.

localStorage keys (prefix "usbToggle.")
theme          "system" | "light" | "dark"   avoids a theme flash before AppInfo arrives
collapsed      { disconnected, hubs }        collapsed sections
pinHintShown   boolean                       the "pinned" tray hint was shown once

==============================================================================
5b. ICON KEYS (ui/icons.js, ui/icon-library.js)
==============================================================================
Built-in keys     usb, keyboard, mouse, input, gamepad, audio, camera, storage, phone, bluetooth, network,
                  printer, serial, security, hub, other (= the Category values), plus mic, speaker, monitor,
                  pen, card, light, fan. The picker's quick row offers 22 of them (ICON_CHOICES).
Library keys      "l-<lucide name>", e.g. "l-guitar"; 239 icons in 16 groups (ICON_LIBRARY.groups).
Color             Category icons use their category color (cat-<category>); extra built-in icons borrow one
                  (ICON_COLOR); library icons use the color of their group.

==============================================================================
6. COMMAND-LINE AND STARTUP ENTRIES
==============================================================================
Arguments: --tray | --hidden | --autostart | --wait-for-pid <pid>
Scheduled task "usbToggle": logon trigger (current user, 3 s delay), RunLevel HighestAvailable,
  InteractiveToken, IgnoreNew, no battery limits, no time limit, action "<exe>" --autostart.
Run value HKCU\Software\Microsoft\Windows\CurrentVersion\Run\usbToggle = "\"<exe>\" --autostart".
