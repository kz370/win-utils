USBTOGGLE CATALOG
=================
One-line index of every module, type, function, constant and UI component.
Format: name [kind] (file) - description. Paths are relative to usbToggle/.

------------------------------------------------------------------------------
MODULES
------------------------------------------------------------------------------
main                [module]  (src-tauri/src/main.rs)        - Binary entry point; calls run().
lib                 [module]  (src-tauri/src/lib.rs)         - Application core: state, IPC commands, tray, window, startup.
devices             [module]  (src-tauri/src/devices.rs)     - USB device discovery and grouping into Device records.
devices::imp        [module]  (src-tauri/src/devices.rs)     - Windows-only SetupAPI/CfgMgr32 code used by the scan.
classify            [module]  (src-tauri/src/classify.rs)    - Pure naming, categorization and parsing helpers.
control             [module]  (src-tauri/src/control.rs)     - Enables and disables a device instance.
control::imp        [module]  (src-tauri/src/control.rs)     - Windows-only class-installer and config-flag code.
config              [module]  (src-tauri/src/config.rs)      - Settings, per-device names/pins/locks, load/migrate/save.
autostart           [module]  (src-tauri/src/autostart.rs)   - "Start with Windows" via logon task or Run key.
autostart::imp      [module]  (src-tauri/src/autostart.rs)   - Windows-only schtasks/reg implementation.
elevation           [module]  (src-tauri/src/elevation.rs)   - Admin detection, elevated relaunch, wait for old instance.
notify              [module]  (src-tauri/src/notify.rs)      - Device-change notifications with debouncing.
paths               [module]  (src-tauri/src/paths.rs)       - Installed vs. portable file locations.
logger              [module]  (src-tauri/src/logger.rs)      - Rotating file logger and log macros.
win                 [module]  (src-tauri/src/win.rs)         - UTF-16 helpers, last error, console-less commands.
app.js              [module]  (ui/app.js)                    - Front-end state, rendering, interactions and IPC calls.
icons.js            [module]  (ui/icons.js)                  - Inline SVG icon set (window.ICONS, window.icon).

------------------------------------------------------------------------------
TYPES (Rust)
------------------------------------------------------------------------------
Core                [struct]  (lib.rs)        - Process-wide state: store, config, devices, busy set, locks, elevation.
Shared              [type]    (lib.rs)        - Arc<Core>, registered as Tauri managed state.
Snapshot            [struct]  (lib.rs)        - Devices + busy IDs + scan time + scan error; IPC payload and "devices" event.
AppInfo             [struct]  (lib.rs)        - Version, elevation, settings, autostart, paths, portable flag, config error.
ToggleResult        [struct]  (lib.rs)        - Outcome of set_device_enabled with the fresh snapshot.
Device              [struct]  (devices.rs)    - One physical USB device as shown to the user.
RawNode             [struct]  (devices.rs)    - Raw data read from Windows for one device node.
DevInfoSet          [struct]  (devices.rs)    - Owns an HDEVINFO handle; destroys it on drop.
NodeInfo            [struct]  (classify.rs)   - Class, names, service and IDs of a node or function.
Category            [enum]    (classify.rs)   - Device type: keyboard, mouse, input, gamepad, audio, camera, storage, phone,
                                                bluetooth, network, printer, serial, security, hub, other.
ActionError         [struct]  (control.rs)    - Error code + readable message of an enable/disable call.
ActionOutcome       [struct]  (control.rs)    - Successful enable/disable result (needs_restart).
Settings            [struct]  (config.rs)     - User settings (theme, tray, startup, display filters incl. hideProblems, protection, confirmation).
DeviceSettings      [struct]  (config.rs)     - Per-device custom name, pin and lock override.
Config              [struct]  (config.rs)     - Root of config.json: schema version, settings, device map.
Store               [struct]  (config.rs)     - Location of config.json; load and save.
AutostartState      [struct]  (autostart.rs)  - Whether the app starts with Windows and whether elevated.
Logger              [struct]  (logger.rs)     - Log file path holder with log().
